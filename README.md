# ページ書き込みツール（Chrome 拡張）

Web ページにマウスやタッチで書き込みでき、スクロールしても書き込みが
ズレずに追従し、書き込み込みでページを保存できる Chrome 拡張機能。

## 特徴

- **描画ツール**: ペン（赤・黒・青・緑）／蛍光ペン（黄・橙・赤・青）／レーザーポインタ／
  直線／矢印／円／消しゴム
- **色付きカーソルプレビュー**: ペン・蛍光・レーザー・消しの各モードで、これから
  書き込む色・太さがカーソル先のドットで分かる（消しは中空の黒い丸で消去範囲を示す）
- **レーザーポインタ**: カーソル先に半透明の色付きドットが追従し、書いた線は
  一定時間（1/3/5/10 秒から選択）で自動的に消える一時的な書き込み。色はペンの色を使う
- **詳細／簡単パレット**: 簡単パレットは**モード直接切替ボタン**（ペン・蛍光・ﾚｰｻﾞｰ・消し・
  マウス）とペン色・蛍光色だけの省スペース表示に切り替えられる。ボタンを押すだけでそのモードへ
  直接切り替えられ、表示するボタンは詳細パレットの「巡回対象」でチェックしたもの＋マウスに絞られる。
  パレットはグリップをドラッグして画面上の任意の位置へ移動できる
- **ページ拡大縮小に強いパレット**: ブラウザのページズーム（Ctrl +/−）を行っても、
  パレットの**見かけのサイズは固定**され、**位置は画面に対する相対位置のまま**（右上に
  置けば右上、中央なら中央）に保たれる。ウィンドウを小さくしても画面外へはみ出さない
- **スクロール追従**: ページ全体を覆う透明 SVG オーバーレイに描くため、
  縦横どちらにスクロールしても書き込みが内容に固定されて追従する
- **ページ保存**: Chrome の `pageCapture` で **MHTML（.mhtml）** として保存。
  元ページの HTML・CSS・画像・テキスト選択・リンクを 1 ファイルに丸ごと保存し、
  書き込み（SVG）も一緒に残る。保存した .mhtml はそのまま Chrome で開ける。

## インストール（未署名のローカル拡張として読み込む）

1. Chrome で `chrome://extensions` を開く
2. 右上の「**デベロッパーモード**」を ON にする
3. 「**パッケージ化されていない拡張機能を読み込む**」をクリック
4. このフォルダ（`page-annotator`）を選択する

## 使い方

1. 書き込みたいページで、ツールバーの拡張アイコンをクリック
   → 右上にツールバーが表示され、描画モードが ON になる
   （アイコンを**右クリック**したメニュー「ページ書き込みパレットの表示／非表示」
   からも表示/非表示を切り替えられる）
2. ツールと色を選んで、ページ上をドラッグ／タップして書き込む
   - ペン・蛍光ペン: ドラッグでフリーハンド
   - 直線・矢印: 始点から終点までドラッグ
   - 円: ドラッグした範囲（始点と終点を対角とする矩形）に内接する楕円を描く
   - **レーザー**: カーソル先に半透明ドットが追従。書いた線は「残存秒」で
     選んだ時間（1/3/5/10 秒）後に消える。色はペンの色を使う
   - 消しゴム: 書き込みの上をなぞると、その線を丸ごと消す
3. **モードの切替（Wクリックで巡回）**:
   - **ダブルクリック**で、**ペン → 蛍光 → レーザー → 消し → マウス → ペン…** の順に
     モードを巡回できる（書き込みは消えない）
   - 「**巡回対象**」のチェックで、巡回に含める状態を個別に選べる（例: 蛍光のチェックを
     外すと巡回で蛍光を飛ばす）。マウスは常に含まれる。有効な状態が 1 つ以下のときは
     ダブルクリック切替が無効になる（右Wでも右クリックメニューが通常どおり使える）
   - ツールバーの「切替操作」で **右W（右ダブルクリック）/ 左W（左ダブルクリック）**
     のどちらで巡回するかを選べる（既定は右W）
   - モードボタン（現在の状態と「次に切り替わる先」を表示）を**クリックしても巡回**できる。
     ペンタブ等でマウスに持ち替えずに切り替えたいときに便利
   - モードボタンを**ダブルクリック（ダブルタップ）すると、一発でマウスモードへ戻る**。
     通常の巡回（シングルクリック）と競合しないよう判定の受付時間は短め
4. 「↶ 戻す」で直前の書き込みを取り消し、「🗑 全消去」で全部消す
5. 「💾 保存」で書き込み込みの `.mhtml` をダウンロード（保存先を選べる）
6. 「✕」でツールバーを閉じる（描画 OFF になり、ページを普通に操作できる）

- ツールバー最上段のグリップ（⠿）をドラッグすると、画面上の任意の位置（上下左右）へ移動できる
- 「詳細／簡単」ボタンでパレットの表示を切り替えられる。**簡単**はモード直接切替ボタン
  （ペン・蛍光・ﾚｰｻﾞｰ・消し・マウス）とペン色・蛍光色のみ。ボタンを押すだけで直接そのモードへ
  切り替わり、表示されるボタンは詳細パレットの「巡回対象」チェック＋マウスに絞られる
- 再度書き込みたいときは拡張アイコンをもう一度クリック

## タブを切り替えてもパレットが消えない仕組み

ツールバーの表示状態・モード・ツール・色・位置は `chrome.storage.local` に
保存され、`storage.onChanged` で**すべてのタブが同期**する。

- Chrome がメモリ節約のため非アクティブなタブを自動破棄（discard）して
  再読み込みしても、content.js は起動時にストレージを読んで**パレットを復元**する
- 拡張アイコンのクリックはストレージの値を反転させるだけなので、
  メッセージ到達のタイミングに左右されず、**ボタンを押せば必ず表示/非表示が切り替わる**
- あるタブで開く/閉じる/モード切替すると、開いている他のタブにも反映される

## 仕組み（概要）

| ファイル | 役割 |
|---|---|
| `manifest.json` | 権限・content script の登録（Manifest V3） |
| `content.js` | SVG オーバーレイ＋ツールバー、描画ロジック |
| `content.css` | ツールバーの見た目 |
| `background.js` | アイコンクリックのトグル、`pageCapture` による MHTML 保存 |

書き込みは `pageX/pageY`（ドキュメント座標）で SVG に記録される。
オーバーレイは `position:absolute; top:0; left:0` でドキュメント原点に
等倍配置されるため、スクロールしても書き込みが内容と一緒に動く。

## 制限・既知の注意点

- `chrome://` などブラウザ内部ページや Chrome ウェブストアでは動作しない
- 書き込みはページを離れる／再読み込みすると消える（保存は MHTML 書き出しで行う）。
  リロードをまたいで保持したい場合は `chrome.storage` への保存を追加する拡張余地あり
- ページ幅が大きく変わるレイアウト再計算（ウィンドウ幅変更など）では、
  横位置がズレることがある（ドキュメント座標方式の仕様上の割り切り）
- 巨大なページは MHTML の base64 データ URL が大きくなり、保存に時間がかかる場合がある
- 消しゴムは「線単位」で消す（部分消去ではなく、触れたストロークを丸ごと削除）
- **切替操作を「右W」にしている間は、パレット表示中のブラウザ右クリックメニューを
  抑止する**（右ダブルクリックのモード切替を確実に検出するため）。右クリックメニューを
  そのまま使いたい場合は、切替操作を「左W」にするか「✕」でパレットを閉じる
- パレットの表示状態は全タブで共有されるため、一度開くと他のタブでも表示される
  （`✕` で閉じれば全タブで非表示になる）

## 今後の拡張余地

- テキスト入力ツール／図形（四角など）の追加
- `chrome.storage` による URL ごとの書き込み永続化（再訪時に復元）
- PNG 書き出し（表示範囲のスクリーンショット）

## 変更履歴

### v1.0.5
- **簡単パレットのモード切替を直接ボタン化**。従来の「クリック/ダブルクリックで切替」する
  単一ボタンを廃止し、**ペン・蛍光・ﾚｰｻﾞｰ・消し・マウス**の直接切替ボタンを配置。押すだけで
  そのモードへ切り替わる（絵文字なしのテキスト表示）。表示するボタンは詳細パレットの
  「巡回対象」でチェックしたもの＋マウスに絞られる（詳細パレットは従来どおり）
- 簡単パレットのボタンは**5 個すべてを 1 行に**収め、レーザーだけラベルを半角カナ「ﾚｰｻﾞｰ」に
  して幅を抑えた
- **蛍光ペンに青（`#40c4ff`）を追加**（黄・橙・赤・青の 4 色に）

### v1.0.4
- **円ツール**を追加（直線・矢印の隣）。ドラッグした範囲に内接する楕円を描く
- ブラウザのページズーム（Ctrl +/−）で**パレットのサイズが連動して変わらない**よう、
  読み込み時の倍率を基準に逆向きの補正を当てて見かけのサイズを固定
- パレットの保存位置を絶対 px から**ビューポートに対する割合**に変更。ページを拡大縮小
  しても**画面上の同じ相対位置**に留まり、ウィンドウ縮小時も画面外へはみ出さないよう
  端でクランプ
- モードボタンの**ダブルクリック（ダブルタップ）でマウスモードへ一発復帰**できるように
  （通常の巡回と競合しないよう判定時間は短め）。ペンタブでマウスに持ち替えずに操作しやすく

### v1.0.3
- ペン・蛍光・消しモードでも、カーソル先に色付き（消しは中空の黒丸）プレビューを表示。
  これから書き込む色・太さ・消去範囲がマウス位置で分かるように
- ダブルクリック巡回を **ペン → 蛍光 → レーザー → 消し → マウス** の 5 状態に拡張し、
  「巡回対象」チェックで状態ごとに巡回へ含める／外すを選べるように（マウスは常に含む）
- パレットに **詳細／簡単** 切替を追加（簡単はモード表示とペン色・蛍光色のみの省スペース）
- パレットをグリップのドラッグで **上下左右どこへでも** 移動できるよう修正
  （以前は最上段の左右にしか動かせなかった `!important` の効き順を是正）
- ツールボタンの並びを **ペン・蛍光・レーザー・直線・矢印・消し** に変更。
  色欄のラベルを「ペン/図形」→「ペン」に簡略化

### v1.0.2
- ダブルクリックによるモード巡回（書き込み → レーザー → マウス）と、
  右W／左W の切替操作の選択、レーザーの残存秒（1/3/5/10）選択に対応
